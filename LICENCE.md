## 🧩 About

**Albion Online Companion** is a curated list of Albion Online open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, session switcher
- **Quality-of-Life Helpers** — inventory catalog, build planner, overlay notes
- **Research Notes** — gathering routes and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Session Switcher — swap between study sessions quickly
- Resource Tracker — visualize node positions on notes
- Route Notes — record and review gathering paths
- Playback Speed — adjust overlay refresh for study (0.1x to 5x)

### Wallhack
- Build Catalog — browse gear, tiers, enchantments
- Custom Loadout Notes — organize player builds
- Highlight Notes — improved visibility of tracked resources

### Aimbot
- Route Mode Notes — segment study on any map
- Zoom Control — manually adjust overlay scale mid-run
- Map Buffer Notes — chain complex routes in the planner
